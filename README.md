# Student Depression Prediction

An educational machine-learning web application for estimating student depression risk from survey-style inputs.

The application uses a trained **Random Forest Classifier** and provides predictions through a FastAPI backend with a custom HTML, CSS, and JavaScript frontend.

> **Educational / Research Use:** This project is not a medical diagnostic tool. Model predictions should not be interpreted as clinical diagnoses.

## Machine Learning

The final deployed model is a **Random Forest Classifier**.

The model predicts two classes:

```text
0 → Lower estimated risk
1 → Higher estimated risk
```

The API returns the predicted class, an estimated probability for the positive class, and an explanatory message.

## Preprocessing

The deployed inference process reproduces the preprocessing used during model training.

It includes:

* Binary encoding for gender and yes/no features.
* Sleep-duration encoding.
* Degree transformation into `Degree_Level`.
* One-hot encoding for `Dietary Habits`.
* Engineered features:

  * `Risk_Flag`
  * `Stress_Index`
  * `Pressure_per_Satisfaction`
* Robust scaling.
* Fixed feature ordering using `feature_columns.pkl`.

The preprocessing objects are saved alongside the trained model so that the API can reproduce the same feature representation during inference.

## Features Used

The deployed model uses:

* Gender
* Age
* Academic Pressure
* CGPA
* Study Satisfaction
* Sleep Duration
* Suicidal Thoughts
* Work / Study Hours
* Financial Stress
* Family History of Mental Illness
* Risk Flag
* Stress Index
* Pressure per Satisfaction
* Degree Level
* Dietary Habits

The original dataset features excluded during preprocessing include:

* Profession
* Work Pressure
* Job Satisfaction
* City
* Original dataset ID

## Degree Level

The original `Degree` feature is transformed into:

```text
0 → School (Class 10 / 12)
1 → Bachelor's
2 → Master's
3 → Doctorate / PhD
4 → Others
```

## Run Locally

From the project root:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI application:

```bash
python -m uvicorn backend.main:app --reload
```

Then open:

```text
Application:
http://127.0.0.1:8000

Swagger API documentation:
http://127.0.0.1:8000/docs

Health check:
http://127.0.0.1:8000/health

Model information:
http://127.0.0.1:8000/model-info
```

## API Endpoints

### `GET /`

Serves the frontend application.

### `GET /health`

Returns the current API health status and whether the trained model is loaded.

### `GET /model-info`

Returns information about the current model mode and loaded model artifact.

### `POST /predict`

Accepts validated student information and returns a prediction.

Example response:

```json
{
    "prediction": 1,
    "label": "Higher estimated risk",
    "probability": 0.9235,
    "message": "Prediction generated by the trained machine-learning model."
}
```

## Validation

The deployed inference pipeline was validated against a real test-set row from the training workflow.

The notebook prediction and the FastAPI prediction produced the same class and matching probability after the saved preprocessing artifacts were applied.

The application was also tested end-to-end:

```text

   ↓

   ↓

   ↓

```

## Safety / Interpretation

This project is intended for educational and research purposes.

A machine-learning prediction does **not** establish a diagnosis, cause, or clinical condition. Model probabilities should be interpreted only as outputs of the trained model on the provided inputs.

The application should not be used as a substitute for professional mental-health assessment or support.
